Valérie's Kitchen — LLM Chatbot

A personalised AI cooking assistant built with GPT and Streamlit. Shows how a generic LLM becomes a focused product through prompt engineering alone: French, Asian and Mediterranean cuisine influences, known pantry staples, vegetarian-first suggestions and natural wine pairings. Includes prompt-injection and off-topic guardrails, response caching, context-window trimming, a session message limit and cost controls.

VerdureAsk — Bilingual RAG Chatbot

A bilingual Retrieval-Augmented Generation (RAG) customer-support chatbot. FAQ content is chunked and embedded (text-embedding-3-small), the most relevant passages are retrieved by cosine similarity, and GPT answers using only that context to avoid hallucinations. Built with Streamlit, the OpenAI API and NumPy, with a security guardrail, response caching and cost controls. Adapting it to a new client only requires replacing the FAQ file.

GitHub Live Demo

Clairvoyant — Global Sector Intelligence Agent

An agentic stock research tool covering US, European, Asian, Indian and Chinese markets across eight sectors. The agent discovers and ranks companies from real market data (yfinance, live FX rates, Wikipedia) and normalises every monetary metric to USD before ranking. GPT is used only to write the comparison table and investor briefing, so it never invents a ticker or a figure. Built with Python, Streamlit, Pandas and the OpenAI API.
